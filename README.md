# 奔馳榮耀島・校慶運動大冒險 (Sports Quest Island)

> **新竹市香山區大庄國民小學「七一大庄、五力飛揚」71 週年校慶運動會 3D 動態導覽與闖關島**  
> *Da-Chuang's 71st: Soaring with the Five Powers*  
> 🌐 **線上體驗網址**：https://dcps-sports-71-island.vercel.app

---

## 🌟 專案特色

1. **香山海風 ✕ 青草地「藍綠白」清爽視覺**：結合海濱藍、草地綠與大庄招牌**六道立體紫色橡膠跑道**。
2. **五力集章護照（Quest Passport）**：
   - 入場領取「運動員註冊卡」，自訂姓名與參賽身分（低年級、中年級、高年級、熱血家長、親善校友）。
   - 畫面上方常駐五力集章進度條（`0/5 章`：道德力、美感力、體能力、群體力、知識力）。
3. **3D 地標點擊尋寶与趣味問答**：
   - 每座島皆設有專屬 3D 地標與互動任務（聽槍響起跑反應挑戰、大隊接力外道超車規則、各年級趣味競賽與舞蹈問答）。
4. **完整大會日程表與賽前個人賽戰報**：
   - 內建運動會當日 `08:00–13:00` 全部 **32 項程序表**（支援五力分類篩選）。
   - 收錄 `10/21–11/25` 運動會前完賽的三至六年級 60m / 100m / 200m 預決賽與六年級大隊接力戰報。
5. **全景 3D 勝利煙火與金牌證書**：
   - 集滿 5 個五力印章後，中央聖火台自動引燃 **全景 3D 勝利煙火**，並頒發可一鍵下載 PNG 或截圖保存的專屬 **「奔馳榮耀五力金牌證書」**。
